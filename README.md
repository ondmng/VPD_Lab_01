\# Лабораторная работа № 1 по ВПД



\*\*Галчев Анастас Аристотелевич\*\*, группа \*\*М3О-104БВ-26\*\*, № \*\*7\*\*.



Цель работы — изучить различные языки программирования, освоить сборку и запуск программ из терминала, а также получить практические навыки работы с системой контроля версий Git.



Реализованы программы на 13 языках: C, C++, Python, JavaScript, TypeScript, Java, C#, F#, Go, Rust, Bash, Prolog и Assembler.



Программы выводят приветствия на английском и русском языках, данные студента, его идентификатор и контрольное значение:



\- \*\*Student ID:\*\* `М3О-104БВ-26/07`

\- \*\*Control:\*\* `304 × 7 = 2128`



Дополнительно реализованы особенности отдельных языков: подсчёт слов в Python, определение длины строки в JavaScript, типизированный объект в TypeScript, форматированный вывод в Java, интерполяция строк в C#, конвейер `|>` в F#, короткое объявление переменных в Go, макрос `format!` в Rust, конвейер команд в Bash и факт с правилом в Prolog.



Ассемблерная программа выводит только английское приветствие.



\*\*Окружение:\*\* Windows 11, x86-64, процессор AMD Ryzen 7 7840HS. Исходные файлы сохранены в UTF-8. Для корректного отображения кириллицы в программах на C и C++ настроен вывод консоли UTF-8. Для ассемблера используется GNU Assembler и GCC.



Все 13 программ проверены. Команды компиляции и запуска приведены в файле \[RUN.md](RUN.md).



Исходный код находится в каталоге `src`, каждая реализация размещена в отдельной папке соответствующего языка.



Работа с версиями проекта выполняется с помощью Git. Используются основная ветка `main`, функциональная ветка `feature/prolog`, удалённый репозиторий и дополнительный клон для проверки совместной работы и разрешения конфликта.
